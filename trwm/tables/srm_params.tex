% Parameter counts for the SRM variants and the Newt baselines.
% Companion to the srm_v_newt_ld / srm_cycles / abl_srm_truncation figures.
%
% Provenance: dynamics counts are the `num_dynamics_params` value each run
% recorded into its own W&B config at construction time. Totals are that count
% plus the shared non-dynamics parameters (encoder + reward + policy prior +
% online Q-ensemble) at the same latent dim, which are architecturally
% identical across dynamics variants. That decomposition reproduces the Newt
% S and Newt S + XL d totals exactly.
%
% Note the two SRM variants are NOT the same model: the abl_latent_dim family
% uses a SwiGLU context net with L_layers=2, the abl_cycles_srm and 3h12l
% families an MLP context net with L_layers=1. Recursion depth (H/L) does not
% change the parameter count -- the core is applied repeatedly.
%
% Requires \usepackage{booktabs}.

  row at a given variant and latent dim shares one recursively applied core, so
  the $1h1l$ and $4h3l$ cells have identical parameter counts and differ only in
  how many times that core is applied.}
