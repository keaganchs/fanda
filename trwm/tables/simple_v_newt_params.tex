% Parameter counts for the SimpleTRM dynamics across the latent-dim sweep.
% Companion to the simple_v_newt_ld figure (SimpleTRM 4h3l / 1h1l vs Newt S / Newt S+XLd).
%
% Provenance: dynamics counts are the `num_dynamics_params` each run recorded into
% its W&B config at construction; totals were reproduced by instantiating the
% world model from each run's config (with L_layers=1, the single-layer core these
% pre-refactor checkpoints actually trained with) and agree with the logged
% dynamics count exactly. Totals = shared non-dynamics parameters (encoder +
% reward + policy prior + online Q-ensemble, identical to Newt S at the same
% latent dim) + the SimpleTRM dynamics.
%
% Recursion depth is not a capacity knob: the 1h1l and 4h3l cells share one
% recursively applied core, so their parameter counts are identical -- the table
% has one row per latent dim.
%
% Requires \usepackage{booktabs}.

  identical and differ only in how many times that core is applied.}
  \label{tab:simple-v-newt-params}
